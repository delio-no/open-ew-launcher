# ⚔️ open-ew-launcher

Быстрый, легкий и открытый нативный лаунчер и апдейтер для клиента **Endless War** (на базе Lineage 2). Поддерживает как **Linux** (через PortProton / Wine), так и **Windows**.

---

## ✨ Возможности

- **Кроссплатформенность**: Работает на Linux и Windows без модификации кода.
- **Мгновенная проверка файлов**:
  - **🔍 Быстрая проверка**: сверяет наличие и размер файлов всего за 1–2 секунды с помощью пула потоков `rayon`.
  - **🛠 Полная проверка**: глубокая проверка CRC32 контрольных сумм всех файлов клиента (необходима при сбоях и битых файлах).
- **Высокоскоростное скачивание**:
  - Многопоточная загрузка и распаковка `.lzma` архивов на лету.
  - Расчет скорости и прогресса в реальном времени.
- **Управление серверами обновлений**:
  - Поддержка официальных зеркал и добавление пользовательских серверов.
  - Встроенный TCP-пинг серверов в миллисекундах (с цветовой индикацией качества связи).
  - Кнопка «🎯 Выбрать самый быстрый» автоматически переключает на лучший сервер по минимальному пингу.
- **Автообновление**:
  - Единая опция: автоматически проверяет манифест при запуске и сразу скачивает недостающие/измененные файлы.
- **Интеграция с PortProton / Wine**:
  - На Linux лаунчер автоматически запускает клиент игры через PortProton с флагами `PW_AUTOPLAY=1` и `PW_USE_RUNTIME=0` (для обхода проблем с pressure-vessel и YetiLoader).
  - На Windows игра запускается напрямую из рабочей директории клиента.
- **Современный интерфейс**:
  - Стильная темная игровая тема (`egui`).
  - Растягиваемый на всю ширину и высоту терминал журнала событий с цветовой подсветкой (ошибки, успех, загрузка, пинг).

## 🛠 Сборка и запуск

### Требования
- Установленный [Rust toolchain](https://rustup.rs/) (версия 1.75+).

### На Linux
```bash
cd open-ew-launcher
cargo build --release

# Бинарник будет готов в:
./target/release/open-ew-launcher
```

### На Windows
Откройте PowerShell или терминал в папке проекта:
```powershell
cd open-ew-launcher
cargo build --release

# Исполняемый файл появится в:
.\target\release\open-ew-launcher.exe
```
Поместите `open-ew-launcher.exe` в папку с игрой (рядом с папкой `system`) или укажите путь к игре в интерфейсе.

## 📂 Конфигурация

Настройки лаунчера (выбранный сервер, путь к папке игры, состояние автообновления) сохраняются автоматически:
- **Linux**: `~/.config/open-ew-launcher/launcher.json`
- **Windows**: `%APPDATA%\open-ew-launcher\launcher.json`
