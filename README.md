## 💡 О проекте

Оригинальный официальный лаунчер проекта Endless War построен на базе Electron/Chromium. На современных дистрибутивах Linux (Ubuntu, Debian, Arch, Fedora) пользователи часто сталкиваются с критическими проблемами:
- Ошибка *"Нет доступа к папке клиента"* из-за несовместимости прав и путей в контейнерах.
- Вылеты контейнера Steam Runtime / pressure-vessel (`PW_USE_RUNTIME`).
- Ошибки античита YetiLoader (код 1005) и DirectDraw/VRAM сбои старого движка игры в Wine/Proton.
- Высокое потребление оперативной памяти (~400+ МБ только на лаунчер).

**Open EndlessWar Launcher** решает эти проблемы:
- 🚀 **Нативный и легковесный**: размер бинарника всего ~17 МБ, потребление памяти ~30 МБ, мгновенный старт без Chromium и Node.js.
- 🐧 **Полная поддержка Linux**: встроенная интеграция с PortProton и чистым Wine с автоматическим выставлением флагов совместимости (`PW_AUTOPLAY=1`, `PW_USE_RUNTIME=0`).
- 🪟 **Нативная поддержка Windows**: прямая работа без эмуляторов и трансляторов.
- ⚡ **Многопоточный апдейтер**: параллельная проверка тысяч файлов и быстрая потоковая распаковка LZMA.

## ✨ Возможности

### 🔍 Мгновенная сверка файлов (Rayon + Hardware CRC32)
- **Быстрая проверка**: сверяет наличие и размер всех 3700+ файлов за 1–2 секунды.
- **Полная проверка (CRC32)**: глубокая сверка контрольных сумм всех файлов игры. Выполняется параллельно на всех ядрах процессора через пул потоков `rayon` с аппаратным ускорением SSE4.2/AVX (`crc32fast`), занимая секунды вместо десятков минут.

### 📥 Высокоскоростное скачивание и докачка
- Потоковая декомпрессия `.lzma` архивов на лету с записью в целевые папки.
- Автоматическое создание недостающих директорий игры (`system/`, `textures/`, `staticmeshes/` и т.д.).
- **Умная докачка**: при обрыве соединения или перезапуске лаунчер не скачивает файлы заново, а продолжает ровно с того места, где остановился.
- Защита прав: перед стартом скачивания лаунчер тестирует доступность папки на запись и выводит понятную ошибку в случае системных ограничений.

### 🌐 Управление зеркалами обновлений
- Предустановленный список официальных серверов обновлений.
- Возможность редактирования, добавления своих серверов/IP и удаления зеркал прямо в окне лаунчера.
- **Встроенный TCP-пинг**: измерение реального отклика серверов в миллисекундах с цветовой индикацией (🟢 <100мс / 🟡 <200мс / 🔴 таймаут).
- **Кнопка «🎯 Выбрать самый быстрый»**: автоматически переключает активный сервер на зеркало с минимальным пингом.

### 🎮 Защита и удобство запуска
- Кнопка **«▶ ИГРАТЬ»** автоматически активируется только тогда, когда клиент проверен, файлы обновлены и файл `system\EndlessWar.exe` физически присутствует на диске.
- При отсутствии клиента кнопка блокируется с подсказкой и предлагает скачать чистый клиент одной кнопкой.

### 🖥️ Современный интерфейс (Dark Gaming Theme)
- Оформление на базе `egui` с темной игровой палитрой.
- Полноразмерный терминал **Журнала событий** на 100% ширины окна с крупным шрифтом (13px), таймштампами `[ЧЧ:ММ:СС]` и цветовой подсветкой строк (зеленый — успех, красный — ошибки, желтый — предупреждения).
- Закрепленный нижний статус-бар: кликабельная ссылка на файл настроек (открывает папку в проводнике/Nautilus в один клик) и версия программы.

## 🚀 Быстрый старт

### На Linux
1. Скачайте бинарник `open-ew-launcher` из раздела [Releases](https://github.com).
2. Сделайте файл исполняемым:
   ```bash
   chmod +x open-ew-launcher
   ```
3. Запустите:
   ```bash
   ./open-ew-launcher
   ```
4. Укажите папку с установленной игрой (или выберите пустую папку для чистой установки) и нажмите **«🔍 Быстрая проверка»** или включите **«Автообновление»**.

### На Windows
1. Скачайте `open-ew-launcher.exe` из раздела [Releases](https://github.com).
2. Поместите файл в папку с игрой (рядом с папкой `system`) или в любую удобную папку.
3. Запустите двойным кликом.

## 🛠 Сборка из исходников

### Требования
- Установленный [Rust toolchain](https://rustup.rs/) (версия 1.75 или новее).

### Сборка под Linux
```bash
git clone https://github.com/your-username/open-ew-launcher.git
cd open-ew-launcher

# Сборка оптимизированного релиза:
cargo build --release

# Готовый исполняемый файл:
./target/release/open-ew-launcher
```

### Сборка под Windows
Откройте PowerShell / Командную строку в папке проекта:
```powershell
git clone https://github.com/your-username/open-ew-launcher.git
cd open-ew-launcher

# Сборка релиза:
cargo build --release

# Исполняемый файл появится в:
.\target\release\open-ew-launcher.exe
```

### Кросс-компиляция из Linux под Windows
```bash
rustup target add x86_64-pc-windows-gnu
cargo check --target x86_64-pc-windows-gnu
```

## 📂 Конфигурация

Все пользовательские параметры (путь к клиенту игры, список зеркал, выбранный сервер, флаг автообновления) сохраняются автоматически при любом изменении в файл `launcher.json`:

| Операционная система | Путь к конфигурационному файлу |
|---|---|
| **Linux** | `~/.config/open-ew-launcher/launcher.json` |
| **Windows** | `%APPDATA%\open-ew-launcher\launcher.json` |

### Пример структуры `launcher.json`:
```json
{
  "game_dir": "/home/user/PortProton/etc/EW",
  "selected_server": "https://s2.hiddenfromhid.site/updater/",
  "servers": [
    {
      "name": "Сервер 2 (Рекомендуется)",
      "url": "https://s2.hiddenfromhid.site/updater/"
    },
    {
      "name": "Сервер 1 (Основной)",
      "url": "https://hiddenfromhid.site/updater/"
    },
    {
      "name": "Сервер 4",
      "url": "https://s4.hiddenfromhid.site/updater/"
    },
    {
      "name": "Сервер 3",
      "url": "https://s3.hiddenfromhid.site/updater/"
    }
  ],
  "lang": "ru",
  "full_check": false,
  "auto_update": true
}
```

## 🧩 Архитектура

```
open-ew-launcher/
├── Cargo.toml          # Зависимости проекта (eframe, egui, rayon, crc32fast, lzma-rs, reqwest)
├── README.md           # Документация проекта
└── src/
    └── main.rs         # Основной исходный код:
                        # ├── AppConfig (загрузка, миграция и сохранение настроек)
                        # ├── WorkerThread (фоновый поток сетевых запросов и I/O)
                        # ├── Check & Update Logic (Rayon par_iter + CRC32 + LZMA)
                        # ├── Ping System (TCP handshake latency resolver)
                        # └── LauncherApp (GUI на egui: Header, Settings, Progress, Terminal, Footer)
```

- **Многопоточная модель сообщений**: GUI-интерфейс (`eframe/egui`) работает в основном потоке и никогда не блокируется. Все длительные операции (сетевые запросы, скачивание файлов, распаковка, сверка CRC32, пинг) выполняются в изолированном фоновом потоке воркера и взаимодействуют с интерфейсом через каналы `std::sync::mpsc`.
